## Overview

COMP 4222 Final Project  
Associated with The Hong Kong University of Science and Technology

Developed a graph neural network (GNN) model to predict COVID-19 case flows across regions using advanced graph-based machine learning techniques.

## Key Achievements

- **GNN Architecture**: Implemented sophisticated graph neural network for capturing spatial-temporal dependencies
- **Case Flow Prediction**: Built models to forecast COVID-19 case dynamics across interconnected regions
- **Temporal Modeling**: Incorporated temporal information to improve prediction accuracy
- **Real-World Application**: Provided actionable insights for pandemic response planning

## Technical Approach

### Graph Construction
- Modeled regions as nodes with connections based on mobility and proximity
- Captured both spatial and temporal relationships in pandemic spread

### Neural Architecture
- Advanced GNN layers for feature propagation across graph nodes
- Temporal components to model disease progression over time
- Multi-scale learning for different prediction horizons

### Validation & Results
- Evaluated model performance on real COVID-19 data
- Compared against baseline methods to demonstrate effectiveness
- Provided interpretable predictions for policy makers

## Technology Stack

- **Graph Neural Networks**: PyTorch Geometric
- **Deep Learning**: PyTorch
- **Python**: Core implementation
- **Data Processing**: Pandas, NumPy

## Impact

Created a data-driven framework for understanding and predicting COVID-19 spread patterns using graph-based machine learning, enabling better-informed pandemic response strategies.
