Splitzy is my personal alternative to Splitwise, created out of frustration with the arbitrary transaction limits imposed by Splitwise.

**🚀 Try it out**: [https://split-wise-world.onrender.com](https://split-wise-world.onrender.com)

## Key Features

- **No Transaction Limits**: Unlike Splitwise, Splitzy allows you to add unlimited transactions without hitting arbitrary limits
- **AI Receipt Scanner**: Powered by machine learning, automatically scan and parse receipts to extract item details, amounts, and participants
- **Intelligent Expense Splitting**: Smart algorithms intelligently distribute costs among friends based on what each person actually purchased
- **Real-time Processing**: Get instant OCR results and automatic split calculations
- **User-Friendly Interface**: Clean, intuitive design for managing shared expenses with friends

## Technology Stack

Built with modern full-stack technologies to provide a seamless experience for expense tracking and intelligent splitting:

- **Frontend**: Vue.js for responsive, interactive user interface
- **Backend**: FastAPI endpoint for high-performance receipt scanning and AI processing
- **Database**: Supabase for real-time database management and persistence
- **AI/ML**: Advanced receipt OCR and intelligent expense parsing
- **Deployment**: Render for hosting the production application

The combination of Vue.js, FastAPI, and Supabase creates a powerful, scalable stack that handles receipt processing efficiently while maintaining a smooth user experience.

## Why Splitzy?

Tired of Splitwise's transaction limits? Splitzy removes that friction and adds AI-powered receipt scanning to make splitting expenses easier and faster. Perfect for tracking group trips, shared housing, and frequent group dinners.
