## Overview

(Jun 2021)

Development and implementation of critical perception and navigation systems for an autonomous robot platform, including stereo vision depth sensing and intelligent path planning.

## Key Components

### Stereo Camera Driver
- **CSI Stereo Camera Integration**: Developed custom driver for CSI (Camera Serial Interface) stereo camera
- **Depth Estimation**: Implemented algorithms to extract depth information from stereo pairs
- **Real-time Processing**: Optimized for real-time performance in robotic systems

### Path Planning System
- **Algorithm Development**: Implemented path planning algorithms for autonomous navigation
- **Obstacle Avoidance**: Integration with depth sensing for dynamic obstacle detection
- **Trajectory Generation**: Computed optimal paths for robot movement
