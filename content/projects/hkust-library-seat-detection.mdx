## Overview

Final Year Project at The Hong Kong University of Science and Technology (Aug 2023 - May 2024)

Led the development of a machine learning-based seat detection system designed to help HKUST students find available seating in the university library.

## Technical Implementation

- **Object Detection**: Implemented YOLOv8 model for detecting chairs and personal belongings in library spaces
- **Pose Detection**: Utilized YOLOv8 Pose to classify whether individuals were sitting or standing
- **Tracking**: Integrated custom-modified Kalman filter for accurate occupancy tracking and state estimation
- **Data Pipeline**: Processed detected occupancy data and sent insights to a database
- **Mobile Integration**: Data supported a mobile application for real-time seat availability

## Technology Stack

- **Machine Learning**: PyTorch, YOLOv8
- **Computer Vision**: Object Detection, Pose Estimation
- **Filtering**: Kalman Filter (custom modifications)
- **Database**: Custom data pipeline for occupancy storage
- **Mobile**: Integration with mobile application

## Impact

The system provides real-time, accurate occupancy information to help students efficiently locate available seating in the HKUST library, reducing time spent searching for seats.
