## Overview

(Jan 2022 - Jun 2022)

Worked as core developer and technical manager of an autonomous aiming and tracking system designed to assist robot pilots in targeting and engaging enemy robots during competitive robotics events.

## Key Responsibilities

- **System Development**: Architected core auto-aim and tracking algorithms
- **Technical Leadership**: Managed development team for robust implementation
- **Motion Prediction**: Implemented predictive algorithms to anticipate enemy robot movements
- **Alignment Control**: Developed systems to dynamically align shooter mechanisms for accurate targeting

## Technical Implementation

### Tracking System
- Real-time tracking of enemy robot positions and movements
- Velocity estimation for predictive targeting

### Prediction Engine
- Motion prediction algorithms to anticipate robot trajectories
- Compensation for movement delays in shooter alignment

### Control System
- ROS-based framework for system coordination
- C++ implementation for performance-critical components
- Real-time response capabilities for dynamic environments

## Technology Stack

- **ROS (Robot Operating System)**: Core framework for robot communication and coordination
- **C++**: High-performance implementation for critical algorithms
- **Computer Vision**: Tracking and detection systems
- **Linux**: Development and deployment platform

## Impact

Significantly enhanced robot performance in autonomous aiming scenarios, providing pilots with intelligent targeting assistance that improved engagement success rates.
